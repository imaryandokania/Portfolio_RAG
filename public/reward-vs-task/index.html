A reward function trains an AI agent. The agent learns what the reward pays for. These results show what happens when the reward misses a rule.

the reward gives a pass the agent did the task the gap is the loophole

Reward that checks only the final outcome

The reward gives a pass to 94% of attempts. 6% did the task.

Reward that checks every rule

Pass rate and task rate are equal. No gap.

Analysis

12 tasks, 36 runs per reward. We removed each rule from the reward one at a time. An optimizer attacked each version. A hidden grader checked whether the task was done.

Each missing rule has a cost

The reward checks fewer rules. The reward gives a pass to more wrong behaviour.

Disagreement shows a weak reward

Five people write a reward for the same task. When the five rewards disagree more, the rewards have more loopholes.

The environment is a simulated office with 12 tools and 12 task types. A hidden grader knows the correct result of each task. The reward sees only the task description. Code: rewardsmith.
